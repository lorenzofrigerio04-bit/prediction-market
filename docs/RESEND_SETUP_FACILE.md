# Qui trovi la guida Resend

Il file con tutta la guida passo-passo si chiama **`guida-resend.md`** nella stessa cartella `docs/`.

- In Cursor: apri il pannello file (Explorer) → cartella **`docs`** → **`guida-resend.md`**.
- Oppure usa **File → Open…** e vai in `docs/guida-resend.md` dentro la cartella del progetto.
